# Banco de Dados

Repositório dedicado ao material da disciplina de Banco de Dados.

## Sobre

Este repositório tem como objetivo organizar e centralizar materiais, exercícios, anotações e recursos relacionados ao estudo de Banco de Dados. Ele pode ser usado para guardar conteúdo teórico, exemplos práticos, scripts SQL, exercícios resolvidos e referências úteis.

## Objetivos

- Registrar os conteúdos estudados na disciplina;
- Armazenar exemplos práticos de consultas e modelagem;
- Organizar exercícios e atividades;
- Facilitar o acompanhamento do curso;
- Servir como referência para estudos futuros.

## Conteúdos que podem ser adicionados

- Conceitos de banco de dados;
- Modelagem conceitual, lógica e física;
- Modelo relacional;
- SQL: SELECT, INSERT, UPDATE, DELETE;
- Joins e subconsultas;
- Normalização;
- Integridade e chaves;
- Transações e concorrência;
- Índices e otimização;
- NoSQL (se o curso abordar);
- Exercícios e projetos práticos.

## Como usar este repositório

1. Clone o repositório localmente;
2. Navegue pelas pastas de acordo com o tema;
3. Consulte os materiais teóricos e os scripts disponíveis;
4. Pratique resolvendo os exercícios propostos;
5. Atualize o repositório com novos conteúdos e anotações.
